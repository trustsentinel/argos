# Changelog

All notable changes to this project are documented here. The format is based on

## [0.1.0] - 2026-09-09
Initial tagged release.

### Added
- Discovery -> broker -> processor -> Elasticsearch pipeline for Bitcoin/Ethereum peers.
- Dockerized explorer and processors wired under Docker Compose with health checks.
- Mock-node end-to-end test, unit tests for the wire-protocol helpers, and GitHub Actions CI.
